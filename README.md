# DevElevate 🚀

## Overview 🌟

DevElevate is an advanced **AI-powered productivity web application** designed to optimize the **developer workflow**. This **mobile-friendly Progressive Web App (PWA)** integrates essential tools into a seamless experience, enhancing efficiency and organization. Whether you require **AI-generated coding questions** 🤖, **in-depth explanations of technical concepts** 🧠, **task tracking** ✅, **note-taking** 📝, or a **Pomodoro timer** ⏳, DevElevate consolidates all these features into one platform.

I built this web app because when I was learning how to code, I wanted to track my progress and solve my problems by reviewing and practicing with questions on specific and easy-to-explain topics. Now, thinking about it, I structured it like a microservice app, where different components function independently without relying on any framework. Also, if you want to contribute to this open-source project, you are more than welcome! 

With **partial offline support**, developers can remain productive even without an internet connection. The application is built using **TypeScript**, **Vanilla JavaScript**, **HTML**, **CSS**, and **Tailwind CSS** 🎨 for the frontend, while **Node.js**, **Express**, and **MongoDB** 🗄️ power the backend. Authentication is securely managed using **Passport.js** (Local Strategy) and **Cookie-Session** 🔐.

What sets DevElevate apart is its **AI-driven functionality**, trained through **Google AI Studio** 🤖 to specialize in technology and software development. This ensures **highly relevant and precise outputs**, eliminating the need for complex prompts. Simply enter a technical term such as **"React"** or **"Python"**, and receive insightful **questions, solutions, or explanations instantly**.

## Key Features 🎯

### 1. **AI-Powered Question Generation** 🤖
   - Utilizes the **Gemini API**, trained in **Google AI Studio**, to generate programming-related questions and solutions.
   - Simply input a topic (e.g., **"React"**)—no additional input required—and receive relevant coding questions with solutions.
   - Ideal for **interview preparation, self-assessment, and skill enhancement**.

### 2. **AI-Based Explanations** 🧠
   - Provides **clear, concise, and accurate explanations** of programming and software development concepts.
   - Exclusively trained in **Google AI Studio** on tech-related topics, ensuring **precise and contextually relevant responses**.
   - Input a term (e.g., **"JavaScript Promises"** or **"Docker Containers"**) to receive an **in-depth explanation instantly**.

### 3. **Task Management** ✅
   - A structured **daily task tracker** tailored for developers.
   - Features **editable task boxes** for efficient progress tracking.

### 4. **Notes Organizer** 📝
   - A dedicated section for **storing and managing important development-related notes**.
   - Perfect for **saving code snippets, project ideas, and technical insights**.

### 5. **Quotes & Developer Insights** 💡
   - A curated collection of **motivational quotes and discussions** from the developer community.
   - Save favorites and explore visually engaging previews for **daily inspiration**.

### 6. **Pomodoro Timer** ⏳
   - Built-in **productivity tool** designed to **enhance focus and time management**.
   - Features **alarms and timers** to facilitate structured work sessions.

### 7. **Secure Authentication System** 🔐
   - **Login and session management** powered by **Passport.js** (Local Strategy) and **Cookie-Session**.
   - Ensures **secure and seamless user authentication**.

### 8. **Progressive Web App (PWA) Capabilities** 🌐
   - **Installable on mobile devices** with **offline functionality** for core features.
   - Provides a **near-native app experience**, accessible **anytime, anywhere**.

### 9. **AI-Powered Auto-Generated Test Cases** 🛠️
   - Automatically generates **test cases** for **coding problems**.
   - Helps developers **debug and validate** their code with **realistic test scenarios**.

## Installation Guide 📥

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/DevElevate.git
   cd DevElevate
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables in a `.env` file:
   ```env
   PORT=5000
   MONGODB_URI=your_mongodb_connection_string
   SESSION_SECRET=your_secret_key
   GEMINI_API_KEY=your_gemini_api_key
   ```

4. Start the server:
   ```bash
   npm start
   ```

5. **Access the app via a mobile browser** and **install it as a PWA**.
